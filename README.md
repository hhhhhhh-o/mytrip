# MYTrip

MYTrip 是一个 AI 旅行信息整理与行程编排工具。它将机票、车票、酒店、活动门票、攻略截图、链接、文字和用户偏好整理成有来源、可修改、可确认、可锁定、可提醒的旅行行程。

> 当前阶段：MVP 旅行列表、独立详情、旅行与行程编辑、本机保存及状态自动流转。推送到 GitHub 后会通过 GitHub Pages 自动部署网页版本。

## 一句话定位

将散落的旅行信息，变成可以真正执行的行程。

## 核心原则

- AI 生成的是可编辑初稿，最终决定权属于用户。
- 固定安排优先于灵活活动，锁定内容不得被 AI 擅自修改。
- 每条信息保留来源；无法确定的字段必须请求用户确认。
- 系统推荐来自可追溯的数据源，AI 不凭空编造地点、时间或营业信息。
- 默认选用低成本模型，并把 AI 设计成可替换、可关闭的增强能力；额度不足时手动功能仍可完整使用。
- 第一版聚焦“导入固定安排 → 确认 → 生成时间线”，控制项目规模。

## 本地运行

```bash
pnpm install
pnpm web
```

当前基础版本使用脱敏示例数据，不调用任何 AI API，也不会产生模型费用。

GitHub Pages 部署地址：`https://hhhhhhh-o.github.io/mytrip/`（首次推送并启用 Pages 后生效）。

已实现的本机数据流程：

- 创建旅行并保存到当前设备；
- 按日期自动归入“正在进行”“即将出发”或“往期旅程”；
- 页面刷新后恢复已保存的旅行；
- 以紧凑列表管理多段旅行，点击进入独立详情；
- 编辑、复制或删除一段旅行；
- 手动新增、编辑或删除交通、住宿、活动、地点与餐饮安排；
- 区分固定安排与灵活安排，并允许锁定已确认的固定行程；
- 按日期和时间自动排序，并提示固定行程之间的时间冲突；
- 旅行结束后原样保留全部记录，并允许通过手动填写或图片识别流程为往期旅行补记行程；
- 从相册选择订单或攻略截图，填写类型与来源，经可编辑的核对页确认后加入时间线。

截图导入目前是前端流程演示：图片不会上传，字段使用示例结果生成。后续接入服务端多模态模型后，将替换为真实识别，同时保留同一套人工核对流程。
